# Sistema-de-Facturación
Es un sistema de facturación y gestión de facturas basado en PHP, diseñado para que los usuarios administrativos creen, gestionen e impriman facturas de productos y servicios. El sistema proporciona una interfaz de panel de administración completa, construida sobre el framework AdminLTE, con funcionalidades para:

Gestión de facturas : Creación de facturas con múltiples conceptos, generación automática de códigos, cálculo de impuestos e impresión de facturas.
Gestión de catálogos : Organización de productos y servicios en categorías con descripciones y precios.
Gestión de Productos y Servicios: Crea, edita y elimina los productos y servicios de tu preferencia.
Configuración del sistema : Gestión de la información de la empresa, los tipos impositivos y los perfiles de usuario.
